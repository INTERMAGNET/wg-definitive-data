# DD.13 (Kyoto) Report of the reported S value analysis of the definitive data for 2023 (94 IMOs)

### Motivation

During past year data-checking process it has recognised that site difference reporting activity and practices varies lot in BLV file:
- some IMOs report observed value from 1-2/year to  each absolute observation session as recommended,
- some IMOs use same fixed (adopted) value for each observation, 
- some IMOs not reporting site differences at all.
INTERMAGNET introduced site difference in 2009 in IBFV2,00 file format, Reporting independent scalar observations by second scalar instrument for the absolute observations and reporting of observed values was made possible, In practice, still many IMOs run only one scalar instrument at the observatory and reduces continuous scalar for the absolutes, The same scalar is used to produce the G (Fv-Fs),
What is level of the reporting of the site differences by IMOs? 

### Data and method

The analysis of 94 IMOs was made available at STEP1 for 2023 (Nov 2024). The observation section of BLV files was first separated (linux: sed)
Amount of the different reported scalar values were sorted out for each IMO:
1. no reported values: all values are either 99999,0 or 88888,0
2. 1 unique value reported (test of reported values by linux: sort and uniq):
   - constant non-missing value in every observation reported real observation, historical value
   - dome IMOs report multiple times exactly same value, which is not realistic
   - The statistics of invidual S values of IMO was generated by code generated MATLAB Copilot

### Reasons found from submissions for the lack of values

1. Historical site difference used as adopted value in data processing.No information, when observed and when controlled last time, Some IMOs just did not adopt the reporting to their data processing,
2. Lack of extra scalar instrument at the IMO, Possible solution: temporal scalar instrumentation to the IMO from somewhere else? List of available of instruments for loan via INTERMAGNET? 
3. All observers are not capable to do site difference observations, only trained for absolutes, Risk of damaging the DI-instrument, Also good quality site difference observations needs careful work,
Experienced staff capable to do check are not visiting site often the IMO
4. The reporting of site difference is not adopted to the definitive data process.

### Conclusion: task to data checkers

1. Take a look of the reported site difference values: are they real observations or fixed values? If not reported, are they still observed and used for baseline calculation, not just not reported,
2. Communicate with IMO about the lack of site difference observations in BLV files and importance of site difference checks, specially in case of challenging data set, These observations might be only way to find contamination at absolute house environment
Engourage the IMO find instrumentation for the site difference checks
